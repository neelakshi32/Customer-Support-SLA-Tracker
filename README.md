# Customer Support SLA Tracker (Excel Automation)
## Project Overview
This project focuses on automation ticket resolution tracking and monitoring SLA (Service Level Agreement) compliance for customer support operations using MS Excel dynamic functions.

## Tools & Functions Used
- **Tool:** Microsoft Excel
- **Functions:** 'IF' , 'TODAY' , 'ISBLANK' , Dynamic Formatting, Data Categorization.
  
## Key Features & Logic
- **Real-Time Days Calculation:** Calculates pending days dynamically against the current date.
- **Automated SLA Status:** Categorizes tickets into **'SLA Breached'**, **'Within SLA'**, or **'Closed'** based on resolution status.
- **Conditional Formatting:** Highlight SLA breaches visually for immediate priority handling.
- **Summary Analytics:** Tracks open vs closed tickets and ticket issue categories.

## Key Business Insights
- Identified operational bottlenecks causing SLA delays i pending support tickets.
- Provided real-time tracking that helps team leads prioritize high-risk tickets before breaching limits.
